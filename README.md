# Backloggd-Bot
A bot for viewing info about users and games on https://www.backloggd.com/  
Uses Cheerio, the Discord bot API and the IGDB API to retrieve info.

Currently Implemented Commands:  
get-info:  
  - This command fetches basic info about a provided user such as their favourite and most recently played games.  
popular-games:  
  - This command fetches the most popular games on Backloggd.com as of right now  
  
Coming Soon:  
game-info:  
  - Displays some basic info about a chosen game  
Visual Overhaul:  
  - Spicing up the command results with updated Discord Markdown designs  
random-game:  
  - Fetches a random game from IGDB and gives some info about it  
top-rated(genre, timeframe):  
  - Displays the top rated games of a certain genre in a given timeframe (all time by default)  
random-review:  
  - Fetches a random review from Backloggd  
user-stats:  
  - Displays statistics about a given user such as total games played, average review score, average amount of games played in a year  
...and more!  
  
  
This bot is not affiliated with Backloggd
